# Certificate images

Folder gambar sertifikat: JPG, JPEG, PNG, atau WebP.

Lokasi gambar diatur pada `portfolio.certificates` di `script.js` halaman utama:

| Kartu | Pengaturan | Contoh lokasi gambar |
| --- | --- | --- |
| Asisten Berdedikasi | `certificates.islab.image` | `assets/cert/sertifikat-islab.jpg` |
| PwC Campus Connect | `certificates.pwc.image` | `assets/cert/sertifikat-pwc.png` |

Gambar ditampilkan utuh dan bisa diklik untuk diperbesar. Nilai yang kosong menampilkan ruang gambar dengan label “Belum ditambahkan”. Tidak ada dokumen sertifikat contoh yang dibuat atau disisipkan.
