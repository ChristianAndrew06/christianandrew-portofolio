# Personal portrait

Foto pribadi dapat disimpan dalam folder ini. Lokasinya diatur melalui `portfolio.profilePhoto` di `script.js`, misalnya `assets/profile/andrew.png`.

PNG atau WebP dengan latar transparan cocok untuk komposisi hero sesuai referensi. JPG juga dapat digunakan. Monogram CA tetap tampil selama foto belum tersedia atau gagal dimuat.
